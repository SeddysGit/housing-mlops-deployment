# Housing MLOps Deployment

This repository demonstrates a simple MLOps deployment workflow using Gradio. The app predicts housing prices based on square footage and number of rooms.

##  Files
- `Housing.csv` – The dataset used for training
- `model.pkl` – A pre-trained linear regression model
- `app.py` – A Gradio web interface for making predictions
- `README.md` – Project documentation and instructions
